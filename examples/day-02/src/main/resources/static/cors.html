Demo CORS — Día 2

Abre esta página en http://127.0.0.1:8080/cors.html. Las peticiones van a http://localhost:8080: cambia el host, así que es otro origen. Abre DevTools → Network y observa las peticiones OPTIONS (preflight).

  1. — petición "simple": sin preflight
  2. — Content-Type JSON → preflight; lee la cabecera Location (expuesta)
  3. — cabecera propia permitida → preflight
  4. — método NO permitido → el navegador bloquea la petición
